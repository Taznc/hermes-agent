4Blocked column: a triage list you can clear from
A toggle on the Blocked column header swaps cards for a nested list: each blocked task with its blockers indented under it, live status on each. The whole point is the right-hand action — cut the edge (DELETE /links) or force the card past its gate, without opening four drawers to work out what is holding it.

Why this is all buildable now. §1 and §4 need no backend work at all — GET /tasks/:id already returns links.parents / links.children, the board cache resolves those ids to titles and statuses, and POST /links + DELETE /links?parent_id&child_id already exist for the ✕ and the add-picker. §2 reads link_counts, which every card already carries. §3 is the only one that touches Python: /board already loads the full task_links table to build those counts, so it just has to also return the pairs.
